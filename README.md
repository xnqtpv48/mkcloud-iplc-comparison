## 泉港 IPLC 是什么：泉州电信进、香港 BGP 出

IPLC（International Private Leased Circuit，国际私用出租线路）是物理层面的点对点跨境专用电路。MKCloud 这类商家交付的形态是一台 VPS：每台机器配 1 个独立入口 IP 和 1 个独立出口 IP，你连入口操作，业务程序从香港出口向外访问。

泉港这条线的具体参数，按官方商店页：

- 入口：泉州电信
- 出口：香港 BGP
- 带宽形态：独享带宽计费，每月流量无限制
- IP：独享 IPv4 x2（入口、出口各一个）
- 端内延迟：1~2ms（产品资料参考值）
- 防护：默认含 100Gbps DDoS 高防，可定制升级，可申请开通无视海外攻击与 UDP 攻击

有一点需要说清楚，免得期望错位：**"端内 1~2ms" 指的是专线段内部的参考延迟，不是你家路由器到香港网站的全程 RTT**。全程延迟等于"本地宽带 → 泉州电信入口 + 端内 1~2ms + 出口 → 目标网站"三段之和。对福建本省用户来说，本地到泉州电信入口这一段天然很短，所以泉州、厦门、福州及周边的用户在这条线上有天然的就近优势；外省用户也能用，只是前一段的路程要自己补上。

另外，出口 IP 不支持外部连入。官方 FAQ 写得很直白：这台机器不能当公开网站、游戏服务端或者支付回调的入口用，它是"出站专用"的。

## 什么人适合泉港，什么人不必多花这笔钱

按已核验的配置和价格，这几类场景和泉港的匹配度最高：

- **怕 DDoS 攻击的业务**：游戏、金融、大促期的电商站点，攻击成本低、损失直接。100Gbps 起步的高防默认包含，不用另购。
- **跨境直播和持续推流**：独享 200M 意味着这 200Mbps 只属于你，理论上可稳定跑到约 25MB/s 的传输速率，不吃共享高峰的亏。
- **多平台账号运营**：入口、出口各一个独享 IPv4，不存在和别人共用 IP 被连坐的问题。
- **全国分布的团队**：这条线的商品页明确写了"无跨省 QoS 限制，无省份限制"，不像多数直连款那样绑定单一省份连入。

反过来说，如果你只是做日常办公、查资料、低频上传，共享流量套餐月付两三百就能解决，为"独享 + 高防"多付二十倍价格没有意义。钱要花在真实的业务约束上。

## 独享带宽和流量计费，到底差在哪

这是选泉港之前最值得想清楚的一笔账。同样是从国内到香港，共享流量档 1TB 月付 358 元，泉港独享 200M 月付 5600 元，差了十几倍，差异集中在三处：

1. **带宽口径**：共享档的 200M 是峰值，高峰期所有用户抢同一池子，官方明说不保证持续跑满；独享档的 200M 只属于你，长时间传输、直播推流这类持续速率敏感的任务才真正用得上。
2. **流量口径**：共享档按双向流量计费，用超暂停；独享档流量无限制，代价是按带宽付费。
3. **防护与限制**：独享高防款默认含 100Gbps DDoS 防护，且泉港商品页明确无跨省 QoS、无省份限制；共享款为防机场滥用采用省级白名单，只允许绑定省份的 IP 连入。

官方知识库里还有一个参考坐标：沪港 IPLC 独享款 5Mbps 档月付 388 元起，走的是"小带宽、不限流量"路线。如果你的持续传输需求在个位数 Mbps，那个档位便宜得多；需要 200M 级别的持续独享带宽时，再回头看泉港。

## 高防能力：宣传怎么说，购买前该问什么

"默认 100Gbps 高防、可定制升级、可申请无视海外攻击与 UDP 攻击"是泉港商品页的原话，这也是这条线区别于普通 IPLC 的核心卖点。

不过官方知识库自己先泼了半盆冷水：防护对象、阈值、清洗范围和触发条件目前没有完整公开，官方明确建议有具体防护需求的用户通过工单确认，而不是只看宣传数字。另外两条也值得记住——高防不等于容灾，海缆故障这类物理层问题照样可能中断；默认无 SLA 保证，需要保障承诺要先谈定制。

所以比较稳妥的做法是：带着你的业务类型（游戏服、交易接口还是直播推流）、预期的攻击规模、是否需要 UDP 放行这几个人工单里去问，把答复留档，再决定下单。

## 常见问题

**泉港 IPLC 5600 元/月起，是不是贵了？**
要看和什么比。和共享流量档比确实贵，但同档位的独享带宽产品里这个价格不算离谱——第三方测评记录显示广港独享 IEPL 的 5M 档约 500 元/月起，200M 级别的独享电路价格进入四位数是行业常态。你付的钱主要在独享带宽、双独享 IP 和默认高防这三件事上。

**1~2ms 是我玩游戏时的 ping 吗？**
不是。1~2ms 是专线端内的参考值，你的实际体验 = 本地到泉州电信入口 + 端内延迟 + 出口到目标服务器。福建用户全程体验最接近这个数字，其他省份要加上到入口的路程。

**出口 IP 算原生 IP 吗？能解锁流媒体吗？**
官方明确：出口为服务器 IP，不保证原生、住宅或流媒体解锁，独享 IP 也不保证平台账号永不被限。第三方 2023 年对 MKCloud 香港出口的实测记录显示欺诈评分较低、IDC 属性明显，做电商和广告运营可用，但对 IP 纯度有极高要求的场景先测再说。

**能拿来当机场用或者给团队外的很多人共享吗？**
不建议。实名认证、白名单机制和用途条款都是冲着"排除机场类滥用"设计的，泉港商品页也写明仅限个人或企业正规用途、禁止回国等违法违规用途。自己团队内部多人共用一台机器是正常使用范畴。

**个人（非企业）能买吗？**
可以。条款口径是"个人或企业正规用途均可"，门槛是实名认证，而不是企业资质。
